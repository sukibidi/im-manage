## Frameworks & Libraries Used
* **Front-end Engine:** Tailwind CSS v4 (Via CDN for modern utility-first presentation layout structures)

## Fulfilled Assignment Requirements Checklist

### 1. Authentication Interface (Requirement 3.1)
* Features a minimalist secure login workspace overlay panel.
* Simulated client-side validation logic built to run without live database overheads.
* Responsive error-handling alert flags bad credential attempts immediately.

### 2. Navigation Matrix (Requirement 3.2)
* Built-in dynamic header containing state-managed buttons.
* Mobile-responsive design incorporating an expandable menu dropdown for compact display screens.

### 3. Advanced Two-Column Dashboard (Requirement 3.3)
* Displays executive KPI summaries reporting asset values and total stock indicators.
* **Layout Structure:** Divided into a strict structural layout:
  * **Left Column:** Hosts the interactive analytics component mapping categorical storage numbers.
  * **Right Column:** Houses priority notification logs pulling warning tags for lines near minimum inventory quantities.

### 4. Interactive Data Views (Requirement 3.4)
* **View 1 (Stock Items Catalog):** A clean tabular data ledger mapping product nomenclature, SKUs, and pricing levels.
* **View 2 (Suppliers Matrix):** A three-column grid layout capturing vendor contacts, registration statuses, and hub distribution nodes.

### 5. Advanced Data Visualisation (Requirement 3.5)
* Includes an interactive, custom-styled Chart.js bar graph element that reflects live metrics proportional to storage units.

### 6. Semantic Content Management & Footer (Requirement 4.4 & Rubrics)
* Strict markup hierarchy mapping metadata, semantic headers, and developer attributes.
* Includes a professional system footer stating operational baselines.

##  Instructions to Test the Prototype

Follow these simple steps to evaluate the application interface on Google Chrome:

1. Visit the live **GitHub Pages Link** listed at the top of this file.
2. To test the **Error Feedback UI**: Enter any random password string and click *Enter Workspace*. A red error notification banner will dynamically appear.
3. To access the hidden secure workspace tabs, input the following credentials:
   * **Username:** `admin`
   * **Password:** `admin123`
4. Click **Enter Workspace**.
5. Once inside the operational dashboard, use the clean menu links (**Dashboard**, **Stock Items**, and **Suppliers**) at the top right to switch dynamically between pages.
6. Click **Logout** at any point to reset and lock the workspace views back to the authorization portal.
